-Приложение для отслеживания эмоций по дням с помощью календаря. 
-Есть счастливая (Happy), нейтральная (Neutral) и грустная(Sad) эмоции. 
-Эмоции можно убирать, изменять.

Как использовать:
 1.Выберите дату в календаре левым кликом мыши.
 2.Нажмите правой кнопкой мыши на любой день.
 3.Выберите эмоцию из контекстного меню:
   :) - Счастливый
   :| - Нейтральный
   :( - Грустный
   Clear - Очистить эмоцию
Технологии: .NET 8.0 Avalonia UI - кросс-платформенный UI-фреймворк ReactiveUI - фреймворк для реактивного программирования MVVM Pattern - Model-View-ViewModel Autofac - DI-контейнер (в основном проекте)
